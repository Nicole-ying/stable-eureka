# EG-RSA Single-Chain Bootstrap

This folder implements the first runnable half of EG-RSA without multi-candidate Eureka search and without iterative reflection/editing.

The pipeline is:

```text
task_description.txt + step.py
  -> EnvironmentUnderstandingAgent
  -> environment_understanding.json
  -> TargetAlignmentAgent
  -> target_alignment_contract.json
  -> InitialRewardSchemaAndCodeAgent
  -> initial_reward_schema_and_code.json
  -> reward_schema.json + reward_code.py
  -> append compute_reward into copied Eureka env_code/env.py
  -> PPO training
  -> evals.json + component_metrics.json + trajectory_summary.json + reward_trace.json
```

Run:

```bash
python -m eg_rsa.run_single_chain --config configs/eg_rsa_single_chain_lunar_lander.yaml
```

The run directory is created under:

```text
experiments/eg_rsa_single_chain/<experiment_name>_<utc_timestamp>/
```

Important design choices:

- The three bootstrap JSON files are generated by the LLM every run. Their outputs are not hard-coded.
- The prompts are fixed under `eg_rsa/single_chain/prompts/`.
- The pipeline is single-chain: exactly one initial reward function is generated and trained.
- LLM backend is configured through `eg_rsa.edit_agent.backend`; currently `ollama` and `deepseek` are supported by the existing EG-RSA LLM client factory.
- Iterative reflection, memory, rollback, and patch editing are intentionally not included here yet.
